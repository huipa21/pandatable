## Scope

## Out of scope

## Contracts to respect

- D-028 establishes Calendar as an M5 view. The reserved config shape is `calendar: { dateField, endField }` (see `docs/08-query-engine.md` §1); validate references against live fields and use existing versioned view-config behavior.
- Accept only supported date/datetime field types. Respect D-117: dates are timezone-free calendar dates; datetimes are instants displayed in the effective field/viewer timezone. Do not round-trip datetime values through lossy JavaScript numbers or silently reinterpret dates.
- Define and test range behavior before implementation: valid start/end type combinations, endpoint/null handling, display boundaries, and how dragging a range updates both endpoints. If existing decisions do not settle these semantics, record the choice as a new D-xxx.
- Rows without a usable start date must remain accounted for; do not silently drop them. Dragging must have a keyboard/touch-accessible alternative and must not show success after a failed or unauthorized write.
- Reuse normal row write, error, permission, and realtime behavior. User-visible strings need matching `en` and `zh-CN` keys. Support dark mode and 390 px width.
