## Scope

  physical FK/junction storage and the corresponding reverse field.
- Implement ACL-checked link/unlink mutations, transactional 1:1 replacement
  after confirmation, and relation-aware row-delete behavior for `set_null`,
  `cascade` and `restrict`.
- Add link-cell chips and a picker modal, restricted to tables in the same book
  (including the current table for self-links).
- Pass AT-401..AT-406 with real PostgreSQL and browser coverage.

Out of scope: lookup/rollup fields (T2.4), formula/filter/view features, cross-book
relations, and unrelated changes to row deletion or field management.

## Contracts to respect

- Preserve the metadata shape and invariants in doc 05: parent/child fields
  belong to their respective tables, targets share `book_id`, self-links use
  distinct fields, and relation storage matches cardinality. A deleted relation
  field removes its relation metadata; service-owned transactions must clean up
  its counterpart and physical DDL consistently.
- Use validated physical names and caller-owned transactions for DDL (D-094..
  D-096); metadata, physical objects, schema versions and row/link changes must
  not be left partially applied. Never concatenate untrusted identifiers or
  values into SQL.
- Follow D-020 for FK indexes. Keep `set_null` as the default. For M:N, cascade
  deletes linked rows on the other side, restrict blocks deletion when links
  exist, and set_null removes junction rows (doc 05 §3). For FK-backed links,
  implement the selected delete policy atomically and return the documented
  translated restrict error.
- Link changes use `POST /rows/{id}/links/{fieldId}` with `{add, remove}`:
  1:N sets/clears child FKs, 1:1 enforces uniqueness and replaces only after
  confirmation, M:N inserts/deletes junction entries (doc 08 §9). Validate row,
  field, relation and target IDs; enforce table ACL on every endpoint.
- Add all visible UI/error strings to both `en` and `zh-CN`; keep picker
  keyboard/touch accessible and use scoped APIs rather than exposing unrelated
  tables.
