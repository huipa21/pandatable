## Contracts to respect

- Analysis recognizes UTF-8, UTF-8 BOM, and GBK; samples at most 1,000 rows. Guess in order: integer, decimal, date, datetime, checkbox, single select (≤20 distinct values with repetition), then text.
- New-table mapping can rename, type, or skip columns. Append mapping targets existing fields or skips columns.
- Stream plain-import rows through the field codec's `ParsePaste`; decode package list and link cells as JSON arrays before validation or link matching (D-189). Use `COPY` batches of 5,000. Invalid cells become NULL and are reported with row, column, and value; make the first 1,000 issues downloadable as CSV.
- Package import restores exact field types/options/constraints and views. For links, offer re-linking by display value only when the target table exists in the target book and the user chooses; otherwise use text and inform the user. Package append mapping is prefilled by field name and compatible type.
- New package-table import is one all-or-nothing transaction. Appends commit progressively by batch and return a result report.
- Respect configured 100 MB file and 500k-row limits. Keep CSV processing bounded in memory; verify AT-705's <300 MB app RSS for 200k rows.
- Enforce write access for imports and deny read-only users. Keep API errors explicit and localized UI strings in both `en` and `zh-CN`.
- Preserve the export package format and hidden `_pandatable` manifest contract in D-034; coordinate the AT-702 end-to-end round trip with T3.7 without taking over export scope.
