### Delivered

- `internal/structure` service + `internal/httpapi/structure.go` routes: `GET /nav`,
  `POST /workspaces`, `PATCH|DELETE /workspaces/{id}`, `POST /workspaces/{id}/books`,
  `PATCH|DELETE /books/{id}`, `POST /books/{id}/tables`, `PATCH|DELETE /tables/{id}`,
  `GET /tables/{id}/schema` (doc 09 "T1.10 structure contract").
- Any active user (including the admin role) creates a workspace and receives a
  direct owner grant atomically. Workspace/book mutations need owner of the
  workspace, table mutations owner of the book; target visibility first (404) then
  parent ownership (403). Admin role never grants access.
- Book creation: generated `b_` schema + `meta.books` in one transaction. Table
  creation: `t_` table with the five system columns, generated `c_` text Name
  column, six `meta.fields` rows (Name display field + five `is_system` fields),
  display-field FK and the default shared Grid view with config, all atomic. Labels
  follow the creator's locale (en/zh-CN). DTOs never expose physical names.
- Locking (D-099): uncached pre-check, `SET LOCAL lock_timeout='3s'`,
  `acl.LockPath` (workspace NO KEY UPDATE, book/table KEY SHARE), actor FOR SHARE,
  uncached recheck. New exports in `internal/acl/structure.go` (`ResolvePath`,
  `LockPath`, `LockActiveUser`, `AccessUncached`) reuse the grants protocol.
  Create/soft-delete invalidate the resolver, including failed/uncertain commits.
- Collision retry (D-100): `ErrIdentifierCollision` or 23505 on
  `books_pg_schema_key`/`tables_book_id_pg_name_key` only; at most 3 whole
  transactions; exhaustion 409 `ERR_DDL_CONFLICT`. Lock waits over 3 s are 409
  `ERR_DDL_LOCK_TIMEOUT`.
- Reorder (D-101): `PATCH {index}` among live siblings, midpoint/front/end or full
  renumber when the gap is <1e-6; workspaces ordered by creation. Soft delete
  (D-036) retains physical objects, metadata, views and grants.
- `/nav` (D-102): levels computed over a small grants query in one repeatable-read
  snapshot, path-only pruning, shared + own personal views; verified node-by-node
  against the resolver.
- Static SQL: fourth sqlc entry `internal/structure/queries.sql` ->
  `structuresql`; no migration, no dependency, auth/ACL/admin generated files
  byte-identical after pinned regeneration. `eventId` is an opaque random id per
  response (D-103); no realtime subsystem.
- Found and fixed by the new tests: `notFoundIfNoRows` wrapped a nil error.
