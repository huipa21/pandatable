## Binding contracts to verify against (not to redesign)

- **Kinds.** The 12 writable batch-1 kinds are `text`, `long_text`, `integer`,
  `decimal`, `float`, `checkbox`, `date`, `datetime`, `single_select`,
  `multi_select`, `email`, `url`. The five system kinds `id`, `created_at`,
  `created_by`, `updated_at`, `updated_by` are read-only and live in the 1e9+
  position block. No new kind, codec or validator belongs in this task.
- **Physical mapping.** Each kind maps to the native PostgreSQL type recorded
  in `docs/07-field-types.md`; columns are generated `c_` plus ten lowercase
  base32 characters and never appear in DTOs. Required/unique/default are
  physical constraints applied through the DDL module inside the caller
  transaction with `lock_timeout`; renames are metadata-only (AT-202).
- **Wire values.** Bigint row IDs and bigint values are canonical decimal
  strings; decimals are fixed-scale strings (precision <= 38); small/int are
  numbers; floats are finite with float32-shortest for real; checkbox is
  boolean; dates are ISO dates; datetimes are UTC instants with up to six
  fractional digits; selects are labels and multi-select follows choice order.
  Never round through JavaScript numbers. Unknown select labels fail writes;
  removed labels stay readable.
- **Required/unique/default preflight (T1.14).** Setting `required` on a field
  with empty cells reports the exact count and requires an explicit default or
  abort (`fillEmpty`); unique rejects duplicates with a translated error; a
  default applies to new rows, and omitted values in inserts fall through to
  the physical default. Field mutations need `If-Match: <field version>` and
  increment the schema version exactly once.
- **System-field visibility (AT-304).** New views hide `id`, `created_at`,
  `created_by`, `updated_at` and `updated_by`; the Fields control can show
  them; `updated_by` must equal the last editor and `created_by` the creator.
  Authorship stays a nullable lowercase UUID with no sharing-directory lookup.
- **Permissions and transport.** Read needs table read, writes need
  write/owner, field and display mutations need table owner. Admin has no data
  bypass; hidden is 404, visible-but-insufficient is 403. Mutations need exact
  Origin, `X-PT-CSRF: 1`, bounded JSON, `no-store` and ten-second deadlines.

### Why the earlier attempts never finished

Every previous `ptdev e2e` attempt hung inside `podman build`, not inside
Playwright. Measured from the Podman VM: `deb.debian.org` 15 s+ per request,
`apt.postgresql.org` 20 s or timeout, `proxy.golang.org` timeout,
`registry.npmjs.org` 8 s. `apt-get update` therefore ran for over 10 minutes.
Killing the run saved no layers, so the next attempt stalled the same way.
Piping output through `Select-Object -Last 80` hid all progress until exit.
The first mirror tried for PGDG (`mirrors.aliyun.com`) was mid-sync and
failed fast on an index size mismatch. `mirror.nju.edu.cn` matched the
signed index.

Working environment for the build (public, credential-free mirrors):

```powershell
$env:APT_MIRROR='http://mirrors.ustc.edu.cn/debian'
$env:PGDG_MIRROR='https://mirror.nju.edu.cn/postgresql/repos/apt'
$env:NPM_REGISTRY='https://registry.npmmirror.com'
$env:GOPROXY='https://goproxy.cn,direct'
```

Always write long gate output to a log file (`*> $log`) and inspect it with
`Select-String`; do not pipe through `Select-Object -Last`.
