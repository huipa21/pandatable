### Actual codec / schema / DDL contracts

- Go `internal/codec`: `Lookup`, `Kinds`, `Bind(kind, json.RawMessage)` returns
  a bound `Field` with canonical Options, ReadOnly, Column, Constraints,
  Decode, Encode, ParsePaste, FormatText, DefaultValue, FilterOps, Aggregates.
  Batch 1 only: text, long_text, integer, decimal, float, checkbox, date,
  datetime, single_select, multi_select, email, url and the five system kinds.
  Unknown/batch-2 kinds fail. Never interpolate raw PGType/options/expressions.
- `Column()` returns typed `ddl.DataType`, forced checkbox NOT NULL/default and
  system marker. `DefaultValue` validates a wire value into a typed literal;
  NULL means no default. Services combine user constraints with the forced
  kind constraints and reject ineligible required/unique/default settings.
  Dynamic defaults require a separately recorded allowlist decision; never
  accept raw expressions. `codec.APIError` maps failures to 400 ERR_VALIDATION
  with safe details.reason/option; unsupported scans remain server errors.
- D-114 defines strict bounded options/defaults. Unknown/duplicate members and
  wrong types fail in Go. fixedTz is checked for syntax/loadability in codecs;
  **the field service must additionally validate PG pg_timezone_names
  membership**, just like profile timezones. Do not trust frontend validation.
- D-115: bigint/row id are canonical decimal strings, decimal fixed-scale
  strings, small/int numbers, finite floats (real float32 shortest), boolean,
  ISO date, UTC datetime with <=6 fraction digits, label-valued selects and
  nullable lowercase authorship UUIDs. Never round JS numbers into int64/numeric
  or microseconds. Decimal precision <=38. Excess nonzero fractional digits
  fail; empty nullable values become NULL, checkbox null/empty becomes false.
- D-117: offset-required datetime Decode; offset-free paste uses effective
  viewing-user/fixed zone. DST gaps fail, overlaps choose earlier instant.
  Copy retains offset/microseconds/historical seconds. D-122 uses explicit UTC
  copy at supported instant boundaries when local year would be 0000/10000.
  Dates/UTC instants are bounded to 0001..9999, with real calendar validation.
- D-118: choices <=500, bounded stable ids, trimmed <=100-code-point labels,
  no controls/comma, unique ids/lower-case labels, closed palette. Values are
  labels, multi arrays in choice order; unknown paste fails, never auto-creates.
  Removed stored labels survive Encode. Record how label edits/removal and
  existing values/defaults are handled atomically; AT-324 is not passed by
  metadata-only rewrites.
- `internal/ddl` is caller-pgx.Tx-only, typed allowlisted descriptors, generated
  prefixes + exactly ten lowercase base32 characters validated before quoting.
  Lock timeout is three seconds. Services own authorization/locks, metadata,
  schema_version, events, commit/rollback and bounded whole-tx collision retry.
  Keep old migrations unchanged. Physical DROP is purge, not soft deletion.
- Existing table creation installs nullable text Name display field, hidden
  system id/created_at/created_by/updated_at/updated_by metadata and one shared
  Grid. Stored default labels use creator **profile** locale. System uiType
  exactly equals its column name; system kinds are not ordinary user fields.
  System values are read-only; display rename is permitted, deletion/type/
  constraint/default mutation is not. Schema DTOs expose no physical names.
- GET `/tables/{id}/schema` returns table, fields, relations (currently empty),
  views, schemaVersion and myLevel. Real routes remain schema-only:
  `/home`, `/w/:workspaceId`, `/w/:wid/b/:bookId`, `/t/:tableId/v/:viewId`;
  `/t/:tableId` replaces to the returned first Grid/visible view. Read actual
  returned ids; do not manufacture view ids or grid data.

### Frontend / authorization / operational invariants

- `web/src/fields/registry.ts` binds pure definitions; BoundField exposes
  normalize/parsePaste/formatCopy/formatDisplay/readOnly/constraints and
  capabilities. `components/fields/FieldRenderer.vue` and FieldEditor.vue are
  native presentation-family components. Static localized field messages,
  safe interpolation/revalidated http(s)/escaped mailto, unknown select/user
  labels, IME-safe validation and no editor for system kinds. Registry/components
  are not imported by any current route. Keep them lazy when integrating later.
  Shared Go/Vitest vectors are lower-layer parity, not production acceptance.
- Field schema mutation/display field requires **effective owner of target
  table** (doc 06); structure rename/delete still needs owner of the parent.
  Admin role has no data-access bypass. Live hidden/missing/trashed path is 404,
  visible insufficient permission 403. Path-only ancestors expose only context
  and visible descendants, never sibling/settings/share/schema controls.
- Mutations reauthorize uncached under workspace NO KEY UPDATE, book/table
  KEY SHARE and actor SHARE, one statement per lock (D-080/D-099). Record any
  stronger field/schema serialization required before implementing it.
  Preserve principal/last-owner serialization D-081..D-087. Any committed
  grant/membership/role/status/lifecycle change or uncertain commit invalidates
  ACL immediately; cache is LRU4096/TTL5s/process epoch, not an authorization
  substitute. Field services own schema version/events and concurrency.
- Existing grants routes: GET `/grants?resource=type:uuid`, PUT `/grants`
  `{resourceType,resourceId,principalType,principalId,level}`, DELETE `/grants/{id}`.
  Scope owner only; only-raise user/group inheritance and active direct user
  workspace last-owner rule remain. Directory search `/directory/users|groups`
  requires resource and explicit bounded q (2..100 code points, <=254 UTF-8
  bytes/no controls), literal case-insensitive substring, first 20 deterministic
  matches plus hasMore; minimal id/name/nullable username, active users only.
  **Do not reuse this owner-only sharing directory for row user-name resolution
  or read/write pickers.** T1.15/T2.1 must record privacy/authorization first.
- Memory-only auth/nav/sharing/schema state cancels/guards stale scope/route/
  identity responses. Share writes serialize/review and reconcile uncertain
  writes. Existing visible 30-second/focus/visibility refresh converges tabs.
  No optimistic permission edits or realtime subsystem exists.
- Mutations require exact Origin and `X-PT-CSRF: 1`, bounded known-member JSON,
  no-store, ten-second deadlines, correlated redacted errors. Field options can
  be large relative to the current 4096-byte HTTP body limit; inspect it and
  **record an explicit bounded field-body decision**, do not globally remove
  limits or silently make 500-choice codecs unreachable. Forced password change
  is 403 ERR_PASSWORD_CHANGE_REQUIRED; disabled/unauthenticated is 401.
  Translate codes/reasons, never server messages.
- All visible frontend strings in en and zh-CN, static keys/runtime-only i18n,
  local locale/theme preferences, both themes, no inline/eval CSP relaxation,
  no new persistence for auth. Initial gzip <600000 and no initial grid imports.
  Do not wire the opt-in synthetic grid into production routes.
- Target host 2 vCPU/4 GB. No dependency without demonstrated need. NFR-1 is

  observations, weaker hashing, extra sign-ins or auth shortcuts. Passwords

- Required uncached PG18 tests use `internal/testdb.Suite`, explicit DSN and
