### Implementation and service boundary

- Added `internal/ddl/identifier.go`, `types.go`, `ddl.go` and two test files.
  `NewIdentifier` uses seven crypto/rand bytes and the first ten complete
  lowercase RFC 4648 base32 symbols: exactly **50 independent bits**, alphabet
  **a-z2-7**, prefixes b_/t_/c_/j_/s_. Tests independently vary every retained
  entropy bit, every alphabet symbol at every position and discarded tail bits.
  Generation errors propagate. Generated and stored names share exact
  prefix/alphabet/length validation; quoted/truncated/legacy-looking 0/1/8/9/
  uppercase/qualified/injection names are rejected, not normalized.
- Names are generated once and stored, never derived from display names.
  DDL returns `ErrIdentifierCollision` plus a sanitized conflict for creation
  collisions. The **future service** distinguishes physical-name metadata
  constraints and retries at most three complete metadata+DDL transactions,
  not statements inside an aborted transaction. No retry manager or implicit
  catalog lookup was added to this physical-only package.
- All seven operations require caller **pgx.Tx** and context. Validation precedes
  any statement; each operation executes `SET LOCAL lock_timeout = '3s'` then
  DDL on that same transaction. No pool/connection API, independent begin/
  commit/rollback, IF EXISTS/IF NOT EXISTS or CASCADE. LOCAL persists until
  transaction completion; caller services must bound earlier locks themselves.
- CreateTable installs exactly `id bigint GENERATED BY DEFAULT AS IDENTITY`
  with `<table>_pkey`, required `created_at/updated_at` default now() and
  nullable UUID `created_by/updated_by`. No physical authorship FKs or update
  triggers. Only generated c_ user columns can be altered/dropped. Restoring
  explicit IDs does not advance the identity sequence; later restore/import
  services must coordinate that when needed.
- `DataType` is a closed native-type enum including documented uuid[].
  Varchar 1..10485760; numeric precision 1..1000, scale 0..precision; irrelevant
  dimensions and raw/case-varied/qualified/injected type strings are rejected.
  Emitted type syntax is pg_catalog-qualified, not search-path-selected.
- Defaults are none, textual literal cast to the validated type, or only
  type-matched pg_catalog.now()/CURRENT_DATE/pg_catalog.uuidv7().
  UTF-8/non-NUL literals escape quotes **and backslashes** as E-strings,
  independent of standard_conforming_strings. This is explicit safe DDL
  construction, not misleading bind placeholders. PG checks representation/
  range; varchar overlength is rejected before the cast to avoid silent
  truncation. Numeric scale uses ordinary native semantics. `"NULL"` as a
  text literal is data; no-default drops the expression. Current user remains
  an application-level default, not injected SQL.
- ColumnSpec has optional required/unique/default. `SetNotNull(bool)` and
  `AddUnique(bool)` explicitly remove constraints; `DefaultValue{}` removes
  a default. Existing values are not rewritten by these changes. Existing
  NULL/duplicate conflicts fail; UNIQUE permits multiple NULLs and uses
  `<table>_<column>_key`. No surprise uniqueness/name normalization.
  AddColumn uses PG's normal default application to existing rows. Physical
  DropColumn is purge, not field soft deletion; dependent views block it.
- Expected states return typed sanitized **400 ERR_VALIDATION**, **409
  ERR_DDL_CONFLICT** or **409 ERR_DDL_LOCK_TIMEOUT**, with both locale keys.
  No raw driver message/detail, SQL, default or row values in domain errors.
  Unexpected errors preserve wrapping for standard correlated HTTP logging/
  redaction. No HTTP route or independent logging framework added.
