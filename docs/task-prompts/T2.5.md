## Scope

- Implement formula lexer, Pratt parser, typed AST, type checker and SQL
  compiler; literals are bound parameters and field references resolve to
  stable field IDs.
- Support the documented v1 operators, types and function library; compile
  formulas at query time and allow references to fields, lookups, rollups and
  other formulas.
- Detect dependency cycles and enforce the documented maximum formula depth.
  Implement `POST /formula:check` with inferred result type or an error position.
- Add formula field configuration/editor UI with field and function
  autocomplete, inline validation errors, and localized strings in both `en`
  and `zh-CN`.
- Pass AT-409: compute its four documented expressions correctly, report an
  invalid expression with its position, and preserve a formula when a
  referenced field is renamed.

Out of scope: filter builder and full filter acceptance (T2.6/AT-410), lookup
or rollup implementation (T2.4), formula evaluation per row in Go, persisted
or generated formula values, and functions outside the documented v1 library.

## Contracts to respect

- Per D-018 and doc 08 §7, formulas are validated SQL expressions compiled at
  query time, never persisted/generated columns or client-provided SQL. Resolve
  identifiers from validated metadata and bind all literals.
- Store field references internally by ID so renames do not break formulas.
  Support formula dependencies on lookup/rollup fields; detect cycles and
  reject dependency depth greater than 8.
- Follow the documented type and runtime semantics: division by zero yields
  NULL; prevent bad casts through type checking (`VALUE()` uses the documented
  guarded conversion); date/time functions use the requesting user's timezone.
- Apply D-044 masking to referenced lookup/rollup values so formulas cannot
  reveal data from a table the user cannot read. Preserve existing ACL and
  field-owner authorization boundaries.
- `/formula:check` and field configuration must use existing API error
  conventions. Keep formula UI usable in dark mode and at 390 px width.
